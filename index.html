SECTION B

Live Coding Comparison

The same task, written two ways. Task: check whether a number is even or odd. Both programs print the same result: Even Number.

manual_even_odd.py MANUAL 
number = 10

if number % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")
Programming logic
Direct conditional: checks if the remainder of number / 2 is 0 and prints the answer immediately.
Coding steps
4 small steps (assign, check, two branches)
Readability
Good and simple
Output
> Even Number
Advantages
Extremely clear for beginners; easy to follow top to bottom.
Limitations
Logic stays inside the file - harder to reuse for other numbers.
ai_assisted_even_odd.py AI-ASSISTED 
def check_even_odd(number):
    if number % 2 == 0:
        return "Even Number"
    return "Odd Number"

print(check_even_odd(10))
Programming logic
Code is wrapped in a reusable function check_even_odd() that returns the answer before printing it.
Coding steps
3 logical steps (define function, return values, call + print)
Readability
Clean, reusable pattern
Output
> Even Number
Advantages
Reusable for any number; separates logic from display; easy to test.
Limitations
A beginner must understand functions before this version makes sense.
i

Important: Both versions are correct and valid. The AI-assisted example uses a reusable function, while the manual example uses direct conditional logic. The function version is not automatically faster or better in every situation - it shines when the same logic must be repeated or reused. Choosing between them depends on the task, the codebase, and the developer's goals.

SECTION E

Advantages and Limitations

Every tool has strengths and weaknesses. Understanding both sides helps developers choose the right approach.

MANUAL CODING

✓ Advantages

  • Builds programming fundamentals
  • Improves logical thinking
  • Gives the developer direct control
  • Helps understand code deeply

✕ Limitations

  • Can take longer for repetitive tasks
  • Debugging can require significant effort
  • Beginners may struggle with errors

AI-ASSISTED CODING

✓ Advantages

  • Can speed up routine coding tasks
  • Suggests alternative solutions
  • Explains unfamiliar code
  • Helps identify possible bugs
  • Supports learning and experimentation

✕ Limitations

  • May generate incorrect code
  • Requires verification and testing
  • Can introduce security vulnerabilities
  • Developers must understand the generated code
  • Quality depends on prompts and context

ABOUT

About Project

Objectives & Scope

This project demonstrates, with simple Python examples, how manual coding and AI-assisted coding compare across development time, debugging effort, readability, learning support, error detection and productivity. The scope is educational and visual: it simulates AI behaviour with pre-written examples and clearly labelled demo metrics. It does not collect real measurements and does not claim scientific proof.

How It Works

A single-page website built with HTML5, CSS3, JavaScript and Chart.js. All programs (even/odd, sign check, largest of two, sum, leap year, factorial) are demonstrated with Python-style code and executed as safe JavaScript in the browser. The AI-assisted tab shows simulated suggestions so the app works fully offline with no API key.

Future Enhancements

  • Connect a real AI API for live generation (user-provided key)
  • Add sorting, searching and string-processing tasks
  • Compare multiple languages (C, Java, Python)
  • Add a quiz to test what the student learned
